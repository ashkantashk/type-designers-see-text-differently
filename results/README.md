# results/

This folder holds the posterior draws the notebook needs and the tables it writes.

The three posterior files are **not stored on GitHub**, because two of them exceed GitHub's file-size limit. They are archived on Zenodo: **[doi:10.5281/zenodo.24152973](https://doi.org/10.5281/zenodo.24152973)**. Download them into this folder before running the notebook. If any of them is missing, the notebook stops in its first section and names the missing file.

| File | Size | Download |
|------|------|----------|
| `posterior_baseline.nc` | 219 MB | [posterior_baseline.nc](https://zenodo.org/records/24152973/files/posterior_baseline.nc?download=1) |
| `posterior_full.nc` | 289 MB | [posterior_full.nc](https://zenodo.org/records/24152973/files/posterior_full.nc?download=1) |
| `posterior_full_with_R8.nc` | 49 MB | [posterior_full_with_R8.nc](https://zenodo.org/records/24152973/files/posterior_full_with_R8.nc?download=1) |

Command-line downloads and MD5 checksums are in the [main README](../README.md#posterior-draws).

`tables/` is filled by the notebook with CSV versions of the manuscript's tables.
